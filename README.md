# AgentWeather

Weather and air-quality forecasting for Faisalabad, Pakistan.

The project will use historical weather and air-quality data to train models and produce forecasts for the next 24 hours.

## Forecast outputs

- Air Quality Index (AQI)
- Temperature (degrees Celsius)
- Precipitation amount and rain probability
- Relative humidity
- UV Index
- Wind speed and direction

## Current status

Initial repository setup is complete. The next step is to check historical data coverage for Faisalabad and build the data collection scripts. Models and the dashboard have not been built yet.
